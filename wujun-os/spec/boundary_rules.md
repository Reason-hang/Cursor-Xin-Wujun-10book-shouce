# 归属边界规则摘要（①–⑫）

> 出处：`spec/v2_方案.md` §5.4。判据一律是**论点的结论句回答的是哪类问题**，不看关键词。  
> 主归属唯一，辅助标签最多 2 个；能力标签 0–2 个且**不参与归属判定**。

## 归属流程（简）

1. 判说话人 → 2. 判是否 X 类排除 → 3. 判主分类（对内 / 对外）→ 4. 按规则①–⑫定支柱 → 5. 打 0–2 个辅助标签与 0–2 个能力标签。  
P3 论点卡只带「候选支柱提示」；支柱最终归属在 P4 聚类后锁定。

## 规则表

| # | 边界 | 规则 |
|---|------|------|
| ① | 做事方法 vs 个人成长 | **怎么做成一件事**归做事方法；**长期怎么积累能力**归个人成长。 |
| ② | 做事方法 vs 判断决策 | **做什么、不做什么的取舍**归判断；**确定做之后怎么做**归做事方法；「做减法」按主干归属。 |
| ③ | 做事方法 vs 数理工程 | 「三条边」类（工程场景怎么做事）归做事方法；**极限、误差等原理**归数理工程；两边可互设辅助标签。（三条边：基线、极限、连接路径） |
| ④″ | 认知格局与境界哲学 vs 个人成长（世界观 / 人生观 / 价值观） | **前者**：认识世界与思考的方法与框架——认知（如何认识、如何思考）、格局、境界、哲学（含吴军评述，第三方标「转述」）。**后者**：个人成长与安放——成长经历与心路、如何学习、三观形成 / 校准 / 安放、心态韧性与幸福。判据：谈「世界怎样运行、怎样认识和思考」归前者；谈「我经历了什么、怎样形成信念与价值、如何安放自己」归后者。 |
| ⑤ | 职业与职场 vs 为人处世与组织协同 | 以**职业发展**为目的归职场；以**合作与关系机制本身**为主归协同。 |
| ⑥ | 商业与创业 vs 财富与投资 | **经营方视角**归商业；**个人资金视角**归财富。 |
| ⑦ | 认知 vs 判断 | **理解框架**（是什么、为什么）归认知；**面向具体选择**归判断。 |
| ⑧ | 情绪、压力、逆境 | 并入个人成长「心态韧性与幸福生活」，不单设支柱。 |
| ⑨ | 创新与产品方法 vs 商业、做事方法 | **从 0 到 1 做出新东西 / 产品的方法**归创新；商业模式与竞争归商业；通用做事流程归做事方法。 |
| ⑩ | 认知·如何思考 vs 数理工程 | **通用思考方法**（理性、经验、推理、科学方法、认识论）归认知·如何思考；**数理、计算机、工程原理及其方法**归数理工程；用「思考」能力标签互标。 |
| ⑪ | 如何学习 vs 教育制度 vs「为什么学」 | **获取、消化、记忆、迁移知识**归个人成长·如何学习；**为什么学、学什么、读书意义**归个人成长（成长经历或三观）；**高考、大学、升学等教育制度**归 X5 排除（含方法论的例外按规则处理）。 |
| ⑫ | 如何沟通 vs 职场沟通 | **沟通机制与方法**（带宽、有效沟通、说服）归协同·如何沟通；**以职业发展为目的的沟通**（展示价值、向上沟通）归职场，加「沟通」标签。 |

## 治理补充

- 分类治理：决策树、判例库（每次裁决一条）、健康度红线（单支柱占比、孤儿卡数）、盲重标。  
- 机读字典与 §13 口径：`spec/pillars.yaml`（一级 10、二级 25）；与本文件冲突时以 §13 字典与 v2 §5.4 原文为准。
