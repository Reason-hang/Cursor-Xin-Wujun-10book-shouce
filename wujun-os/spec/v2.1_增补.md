## 2. 执行架构：EP 骨架（O3 + O6）

> 完整对比、十项机制、Turn 协议与压力测试见 `spec/长任务稳定性与上下文工程方案.md`。本节只固化相对 v2 的**架构裁决**。

### 2.1 推荐组合（EP）

采用：**O3 + O6 为骨架**，内嵌 O9（分层 map-reduce）为工作流结构，叠加 O11（规则复述）与轻量 O5（检索）；降级用 O7（人在回路）、O8（缩范围）；O4 仅在平台支持子 Agent 时可选。

| 组件 | 职责 | 在本项目中的落地 |
|---|---|---|
| **O3 状态外置 + 工单制无状态 Worker** | 状态进仓库；每轮一张自包含工单；开场复水、收尾写回 | `state/`、`spec/constraints.md`、工单板、`handover/` 自动生成；**对话不承载必须保留的信息** |
| **O6 脚本优先流水线** | 切分、对账、去重、锚点、lint、汇总由脚本产出；LLM 只做语义判断 | `scripts/` S00–S08、`make gates`；**完成判据 = 闸门通过**，不是「我觉得做完了」 |

### 2.2 O3 与 O6 为何缺一不可

| | O3 | O6 |
|---|---|---|
| 解决的问题 | 状态放哪里、跨窗口/压缩后如何续跑 | 哪些事不该交给 LLM、数字如何可复算 |
| 关系 | 互补：O9 各层产物（单元、论点卡、概念簇、模型卡）是**可落盘工件**，承载 O3；O6 保证每层指标可脚本复验 |

### 2.3 三句执行纪律（相对 v2 §15 的强化）

1. **对话易失，仓库为真相**——跨轮保留项必须写入有版本、可校验的文件。
2. **一轮一工单**——只加载「常驻摘要 + 本工单 + manifest 列出的最少文件」；收尾必须更新状态并输出交接块。
3. **「我记得」须被「脚本验证过的文件」替代**——约束见 `constraints.md`；分母与进度数字由脚本产生。

### 2.4 与 v2 的衔接

| v2 已有 | v2.1 / EP 强化 |
|---|---|
| §15 每轮协议、§15.11 注意力、§15.13 变更 | 工单制、上下文预算、复水测验（≥11/12）、压缩后**不信摘要、只信复水** |
| §7.7 断点续作 | 单写者、交接文档由状态生成、`pack.py` 快照 |
| §7.8 降级 Z1–Z3 | 与 EP Z0→Z1→Z2→Z3 触发条件对齐（缩范围须你批准） |

**入场条件**：EP-0 压力测试（稳定性方案 §8，含冷启动 ST-2、断点 ST-4 等）未通过前，**不进入全量 P3 批处理**。

## 4. 交付批次、MVD 与阶段快照

> 源自 `handover/项目交接文档.md` §10.6；v2.1 **纳管**为规格级规则（不仅交接文档附录）。

### 4.1 原则

额度中断已发生：**一次只做一个批次**；每批先交 **最小可交付（MVD）**；每批结束打快照并**立即**交给你；不攒到最后。

| 概念 | 定义 |
|---|---|
| **批次顺序** | 固定顺序分批；先做「丢了最痛、最能独立使用」的部分 |
| **MVD** | 可独立使用、独立验证、下一 Agent **无损接手**的最小成果集 + 对应状态快照 |
| **阶段快照** | 每批结束运行 `python3 scripts/pack.py` → `dist/wujun-os-pack_<日期>.zip`（含 MANIFEST 哈希）；命名 `S-{阶段}-{序号}` |
| **触发** | 每批结束；额度告警；上下文临界或发生压缩；你要求时 |

### 4.2 本轮文档交付批次（B1–B3）

| 批次 | MVD | 追加 | 快照 |
|---|---|---|---|
| B1 | 交接文档、开场提示词、恢复包 | — | S-DOC-1 |
| B2 | **本文件（v2.1 增补）** | 稳定性与总纲已单册交付；轮次口径写入 §3 | S-DOC-2 |
| B3 | 机读字典、角色提示词、阶段追加段、全量自测 | 最终恢复包 | S-DOC-3 |

### 4.3 执行阶段批次顺序与 MVD

| 阶段 | MVD | 批次顺序 | 快照 |
|---|---|---|---|
| EP-0 | 仓库目录、冻结、S00–S01、状态文件雏形 | T-00-01 → 03 → 05 → 04 → 06–08 | S-EP0 |
| P0 | D5 输入登记、各书单元计数、缺号清单（先于完整清单） | G0 → G1 → G2/G3 → G4/G5 → G6/G7 → G8 | S-P0 |
| P1 | 3 单元微试跑卡 + 试点报告草稿 → 放量约 14 单元 | 微试跑 → 放量 → 双盲重抽 → 压力测试 | S-P1 |
| P2 | 六本成书分诊表先行 | 成书 → 谷歌 → 来信2 → 来信3 → 来信1 | S-P2 |
| P3a | 单书论点卡、书级回顾、台账，闸门全过 | **态度 → 富足 → 境界 → 格局 → 数学通识 → 见识** | 每本 `S-P3a-{书码}` |
| P3b | 来信集 A/B 层卡与台账 | **谷歌方法论 → 来信2 → 来信3 → 来信1** | 每部 `S-P3b-{书码}` |

| P5 | 先写第 6 章 D06 与场景入口、T1 工具 | 按 v2 §14.7 写作顺序 | 每章 `S-P5-{章}` |

### 4.4 与降级阶梯的关系

连续两次额度中断（当前 1/2）或预计总轮次 >70 且 P1 实测每轮 <2 批等，触发 **Z1 缩范围**（须你批准）；规则见交接 §10.4。批次规则与 Z1 **同时生效**：即使缩范围，仍须每批 MVD + 快照。
