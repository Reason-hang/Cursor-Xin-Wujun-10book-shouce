# 复水测验（15 题题库，每次抽 12 题，≥11 题正确才可开工）

答案以当前规格为准；先自答，再对照。

**Q1. 一级支柱有几个？分别是什么？**

答：10 个：D01 认知格局与境界哲学；D02 个人成长与世界观/人生观/价值观（含心态韧性与幸福生活）；D03 判断决策与风险止损；D04 数理与计算机思维与工程思维；D05 做事方法与执行力；D06 职业与职场；D07 为人处世与组织协同；D08 商业与创业；D09 财富与投资；D10 创新与产品方法（须过三道门，不过则降为 9 个）

**Q2. 两大分类各含哪些支柱？**

答：对内 = D01–D04（4 柱）；对外 = D05–D10（6 柱）。每柱只有一个主分类

**Q3. 二级、三级的数量规则是什么？**

答：不设硬上限。目标区间 L2 22–28、L3 32–44；预警线 28/44；红线 32/50，超出须用户批准。v0 候选 25 个 L2、约 37 个 L3。变体卡等不占配额。（三档数值待用户确认）

**Q4. 覆盖口径的三层是什么？**

答：单元处置率 100%；核心论点覆盖（P4 冻结 K 论点分母，逐书 100%）；抽检召回样本 100%（有漏补抽补写）。覆盖不等于每句话入手册

**Q5. 单元口径？处置标签？**

答：总 1,742 个单元 = 内容 1,697 + 结构容器 32 + 非内容 13。标签 K 核心论点、M 并入、C 案例、X 排除（带子类 X1–X8 与理由）、N 非内容或结构

**Q6. 锚点规范？它能证明什么、不能证明什么？**

答：句级区间（≤800 字）+ 行号 + SHA1 + ≤3 指纹词。只证明"这段文字确实在这个位置"，不证明转述忠实；忠实靠语义抽检和用户抽查 20 张。手册不放长引文，直引 ≤15 字

**Q7. 说话人规则？**

答：先判说话人。读者发言、第三方转述、史实不进"原著核心判断"；吴军转述他人要标"转述"；不确定标"待核"，P4 前清零

**Q8. 归属判据？**

答："结论句测试"：写出结论句，看它回答哪类问题；不看标题、关键词、书名。冲突时查 §13.4 辨析表和规则①–⑫，必要时写判例

**Q9. 哪些内容不作支柱、默认排除？**

答：宏观经济、科技趋势、文明与世界历史、教育制度与升学与家庭与亲密关系不作支柱，归 X4–X6；游记、移民默认排除，可点名拉回；含可迁移方法论的单元只抽方法论

**Q10. 读法层与批大小？**

答：A 精读（六本成书、周末互动与回信精选、骨架类、领域直连）；B 标准（问答、高信号来信）；C 快处置（其余来信）。批 3–5 万汉字，单元整块；单次读取 ≤2 万字；问答默认 B 层通读

**Q11. 交付物有哪些？**

答：D1 主手册、D2 行动工具集、D3 溯源与处置台账、D4 覆盖与质检报告、D5 00_内容盘点与单元清单、D6 方案决策与裁决记录，加里程碑进度台账；只用 Markdown

**Q12. "三条边"指什么？**

答：基线、极限、连接路径（已用谷歌方法论第 008 封信核实），不是成本、质量、时间三角。"三条边"类在工程场景怎么做事归做事方法，极限、误差等原理归数理工程，互设辅助标签

**Q13. 能力标签怎么用？**

答：思、学、沟、做，每卡 0–2 个，不强制，不占配额，不参与归属判定；只用于 4 张能力速查表。薄簇条款：K 卡 <8 或来源 <2 本书则降级为 L3 加标签

**Q14. 当前处于哪个阶段？下一步是什么？**

答：第二步（规划）已完成，v2 方案与增补已交付；P0 未开始；等待用户确认 v2 §18 的 ★1–★4 与 EP 稳定性方案。确认后：EP-0（T-00-01 至 T-00-08）→ P0（T-P0-01 起）
