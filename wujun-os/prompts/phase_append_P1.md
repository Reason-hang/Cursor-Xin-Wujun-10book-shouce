# 阶段追加段｜P1 试点门

> **用法**：粘贴于通用开场提示词之后；抽卡工单加载 `prompts/R-EXT.md`；T-P1-12 / 压力测试加载 `prompts/R-AUD.md`（**全新窗口**）。规格：`spec/v2_方案.md` §15.5.2、§7.5、§7.8。

## 本阶段目标

在全量批处理前验证：抽卡规程、锚点工具、关键词反查、**双盲重抽重合率**、来信3 划重点召回、能力标签可标注率；冻结 **规则 v1**；输出《试点报告》并通过 **ST-2、ST-3**（T-P1-12）。

## 本阶段主角色

| 角色 | 工单 |
|---|---|
| R-EXT | T-P1-01–T-P1-11 |
| R-AUD | T-P1-12（ST-2 压缩模拟、ST-3 漂移回归） |
| R-ORCH | Gate-P1、降级 Z1/Z2/Z3 升级、试点结论用户确认 |

## 执行要点（11 步压缩清单）

1. 按 §7.5 选样（脚本 + 用户过目）→ 覆盖 **14 类样本**
2. 用户确认后按 §15.7 逐单元抽卡 → `data/cards/` 试点卡，字段齐全
3. 每卡 S11 锚点 make + verify → **100%**
4. 6 个回归组 S13 关键词反查 → 命中段落有去向
5. **隔一轮**双盲重抽（**不看首次卡与首次推理**）
6. S14 重合率 → **≥0.7 通过**；0.5–0.7 修规则补试点；**&lt;0.5 停线问用户**（§15.12）
7. 来信3 样本对照「划重点」→ 召回 **≥90%**
8. 能力标签可标注率、归属歧义率统计（§7.5）
9. 记录耗时与上下文 → 建议每轮 2 批或 3 批
10. 复盘 → 变更控制 → **规则 v1**
11. 《试点报告》→ 用户确认是否降级

## 本阶段输入清单

- Gate-P0 已通过；D5 与分母已用户确认
- 试点选样表、本批 `src_frozen/` 单元片段
- `spec/schemas/` 论点卡字段、`rules/concept_watchlist.csv`（S13）
- `data/gold/`（ST-3）

## 本阶段输出清单

- 试点 `data/cards/`、锚点表
- `logs/g10_kw.md`、重合率与召回统计
- 规则 v1、`state/changes.md` 相关条目
- 《试点报告》、T-P1-12 压力测试报告

## 本阶段红线（追加）

- 双盲轮 **禁止**读取 R-EXT 首次抽卡时的对话或推理摘要。
- **禁止**无锚点试点卡进入 S14。
- **禁止**重合率 &lt;0.5 时自行降级或继续 P2；须用户决定（§7.8）。
- 每批仍遵守：转述 ≤60 字、说话人先行、一批一校验（试点批量较小但规程不变）。

## 本阶段停线条件

| 触发 | 处理 |
|---|---|
| 重合率 &lt;0.5 | 停线；§15.12；修规则或换单位由用户定 |
| 重合率 0.5–0.7 | 不进入 P2；补试点与规则修订 |
| ST-2 或 ST-3 失败 | 不进入 P2；修稳定性机制并重测 |
| 选样缺类 | 补选，不缩小 14 类覆盖 |
| 锚点批量失败 | §15.10 #3–#5；仍失败则停 |
| Gate-P1 用户未确认试点结论 | 不领 T-P2-01 |
