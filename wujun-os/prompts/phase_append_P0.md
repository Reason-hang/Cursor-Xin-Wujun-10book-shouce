# 阶段追加段｜P0 冻结与盘点

> **用法**：在通用开场提示词（`handover/开场提示词.md` 或 `AGENTS.md`）之后粘贴本段；工单角色以 `prompts/R-OPS.md` 为主，阶段门由 R-ORCH 裁决。规格：`spec/v2_方案.md` §15.5.1。

## 本阶段目标

冻结 10 本事实源，建立可复算的单元清单与 G0–G8 对账链，产出 **D5《内容盘点与单元清单》** 与 **进度台账 v0**，并冻结分母（总单元、内容单元、汉字数）。

## 本阶段主角色

| 角色 | 职责摘要 |
|---|---|
| R-OPS | S00–S08、`split_*.yaml`、异常台账技术项、D5 生成 |
| R-ORCH | T-P0-12 用户确认门、Gate-P0、阻塞与变更升级 |

## 执行要点（12 步压缩清单）

1. 工作区 + `make freeze` / S00 → `src_frozen/`、`logs/g0_inputs.md`（10/10，文件名 UTF-8）
2. 10 份 `rules/split_<书码>.yaml` 与 §3.2、§6.1 前置发现一致
3. S01 切分 → 总单元 **1,742 = 1,697 + 32 + 13**（不符先查原因，**不改数**）
4. S02 行覆盖与汉字守恒 → 缺口 0、重叠 0、差 0
5. S03 编号连续 → 缺号逐条定性
6. S04 目录一致性（含谷歌 219/223）
7. S05 重复扫描与双出处登记
8. S06 非原著与风险标注 → 无未分类项
9. S07 反向抽查 ≥100 位置、≥60 单元，差异 0
10. 异常台账 100% 定性；无法判断 → 待确认问用户
11. S08 → D5；G0–G8 全过
12. 交付 D5 + 台账 v0，**请用户确认缺号定性与分母**

## 本阶段输入清单

- `_打包吴军10本电子书.zip`（或已冻结的 `src_frozen/` + `MANIFEST.sha256`）
- `spec/v2_方案.md` 附录 B.1、§6.1
- `Makefile`、`scripts/s00_freeze.py` … `s08_inventory.py`（以仓库为准）

## 本阶段输出清单

- `src_frozen/`（只读）
- `data/units/`、`logs/units_index.csv`、`logs/g2.md`–`g8.md` 等
- `out/00_内容盘点与单元清单.md`（D5）
- 异常台账、进度台账 v0
- `state/journal.md` 本轮条目

## 本阶段红线（追加）

- **禁止**在单元总数对不上时改脚本常量或日志数字过关。
- **禁止**未过 G2–G8 即宣布 P0 完成。
- **禁止**在用户确认 ★ 项与 T-P0-12 分母确认前进入 P1。

## 本阶段停线条件

| 触发 | 处理 |
|---|---|
| 任一 G0–G8 失败 | 停；修规则或脚本后按工单 **整体重跑** 受影响步骤 |
| 单元总数与基线不一致且原因未书面定性 | 停；异常报告 |
| 冻结哈希与交接文档 §16 不一致 | 停；§15.10 #22，问用户 |
| 缺号无法判断 | 列入待确认，不进入 S08 终局 |
| 用户未确认分母与缺号定性 | Gate-P0 不通过，不领 P1 工单 |
