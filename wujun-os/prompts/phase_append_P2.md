# 阶段追加段｜P2 分诊

> **用法**：粘贴于通用开场提示词之后；加载 `prompts/R-EXT.md`。规格：`spec/v2_方案.md` §15.5.3、§15.11。

## 本阶段目标

为全部内容单元建立 **单元卡** 与 **读法层 A/B/C** 分诊，完成 S10 批次装箱（3–5 万汉字 / 批），核对强制规则，系列成组 91/91，X 候选抽样回读，汇总规模并交用户确认读法层后进入 P3。

## 本阶段主角色

| 角色 | 职责 |
|---|---|
| R-EXT | T-P2-01–T-P2-10 全程 |
| R-ORCH | Gate-P2、读法层规模确认、Z1 评估升级 |

## 执行要点（10 步压缩清单）

1. S09 → `logs/unit_cards.md`（每内容单元一张）
2. S10 → 批次清单（3–5 万汉字，**单元整块**，系列不拆）
3. **每批前**复述规则摘要卡（§15.11，≤300 字）
4. 标读法层 A/B/C、候选支柱 ≤2、能力标签候选、说话人风险、X 候选及子类
5. 脚本核对强制规则：问答 **B**、周末互动 **A**、骨架 **A**、领域直连 **A** → 执行率 100%
6. 系列单元成组 → **91/91**
7. 批末回顾 → 三要素齐
8. X 候选抽样回读 **≥30**（核心论点遗漏 0；漏判扩样 60 并重判）
9. 汇总各层单元数、字数；更新批数 / 轮次估算；评估 **Z1**
10. 交付分诊表（并入进度台账）→ **用户确认读法层规模**

## 本阶段输入清单

- Gate-P1 已通过；规则 v1 已冻结
- `data/units/`、`src_frozen/`（抽样回读 X 候选时）
- `spec/exclusions.yaml`、X1–X8 口径
- S09/S10 脚本与 `rules/split_*.yaml`

## 本阶段输出清单

- `logs/unit_cards.md`、批次清单（`batches/` 或工单路径）
- 分诊表（读法层、支柱提示、X 子类）
- 系列组表、X 抽样记录、分诊汇总
- 更新后的进度台账

## 本阶段红线（追加）

- **禁止**跳过 §15.11 规则摘要即大批量标分诊。
- **禁止**为降字数破坏「单元整块 / 系列不拆」。
- **禁止**无读法层的内容单元进入 S10 装箱终稿。
- X 排除须有子类与理由；争议用 X8 并问用户（§15.10 #26）。
- 分诊阶段 **不写** 完整论点卡（属 P3）；仅标候选与读法层（除非工单明确重叠）。

## 本阶段停线条件

| 触发 | 处理 |
|---|---|
| 强制规则核对 &lt;100% | 修正漏标后重核 |
| X 抽样发现核心论点遗漏 | 扩样 60；修判定规则；重判受影响类 |
| 91 系列组未齐 | 不交付 T-P2-10 |
| 用户未确认读法层规模 | Gate-P2 不过；不生成 P3a 批次工单 |
| Z1 触发（规模 / 吞吐） | 停线报 R-ORCH / 用户 §7.8 |
| 需改读法层或排除准则（大变更） | 变更控制 + 用户批准 |

## 与 P3 的衔接

- P2 交付确认后，由 S10 清单生成 **T-P3a-B-nnn** / **T-P3b-B-nnn** 模板工单。
- P3 批循环将加载 `phase_append` 的 P3 段（待后续入库）；本阶段须保证批次清单与分诊表哈希写入 `state/journal.md`。

## 本轮对话协议

握手：**阶段 P2**、当前分诊批 / 汇总进度、规则 v1 版本。结尾：各层单元数与字数表摘要、是否待用户确认规模、风险 3 条。
