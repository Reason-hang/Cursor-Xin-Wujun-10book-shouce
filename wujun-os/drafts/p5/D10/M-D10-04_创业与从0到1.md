#### M-D10-04 创业苦差事、蚂蚁与大象　[核心卡]

- 所属：D10-1｜主分类：对外｜稳定度：永恒原理
- 能力标签：做｜辅助标签：D08-1

1. 解决什么问题：迷信从 0 到 1 神话、或与大公司硬拼规模时，如何选战场。
2. 原著核心判断：创业不等于神话式从 0 到 1，规模化与商业闭环同样关键；创业是长期苦差事；小公司凭灵活与不对称优势可改写格局；竞争框架可从规模之争转为新旧技术时代更替；创始人要懂销售与现金流；明星高管创业易败因名望≠市场能力；避坑含伪需求、合伙人错配、现金流与法律结构。
3. 前提与边界：
   - 原著边界：创业方法；职场选择归 D06。
4. 跨书关系：补充 → M-D08-03；补充 → M-D09-02 现金流。
5. 数理工程表达：可检验映射——不对称优势是否写成一句可验证命题。
6. 行动方法：输入（创业想法）→ 判断（伪需求/现金流）→ 步骤（T-12、小步验证）→ 输出（继续/停止）→ 复查（里程碑）→ 退出（融资或关停）。
7. 例子与反例：反例——只有技术无销售与现金流计划。
8. 出处：P3a-JS-U0014-K01；P3a-JS-U0021-K01；P3a-JS-U0020-K01；P3a-JS-U0022-K01；P3a-JS-U0023-K01；P3a-JS-U0016-K01；P3a-JS-U0019-K01；P3b-WJ2-U0063-K01
9. 落地映射（可缺省）：映射·非原著——从 0 建模块时选最小闭环（单仓单渠道），再平台化。
