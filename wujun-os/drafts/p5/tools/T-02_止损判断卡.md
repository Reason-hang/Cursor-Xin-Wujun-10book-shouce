#### T-02 止损判断卡　[T1]

| 字段 | 内容 |
|---|---|
| ID | T-02 |
| 名称 | 止损判断卡 |
| 触发条件 | 投入已大但指标恶化，或诱惑「再加一点就能翻盘」 |
| 输入 | 已投入（沉没）；剩余风险；预设拐点信号；机会成本选项 |
| 步骤 | ① **沉没识别**：若决策不含已投入仍会做吗（锚：P3a-GJ-U0015-K01）② **拐点**：有无可验证好转信号（锚：P3b-WJ2-U0193-K01）③ **厄运链**：是否越陷越深（锚：P3a-GJ-U0015-K01）④ **基率**：成功故事是否幸存者偏差（锚：P3b-GG-U0324-K01）⑤ **执行**：小亏离场或写 J 曲线条件（锚：P3b-GG-U0343-K01） |
| 输出 | 止损 / 有条件坚持（写明触发日期与指标） |
| 复查方式 | 到期日复核指标；禁止无记录加仓 |
| 退出条件 | 资源已转入下一选项或坚持条件已触发 |
| 异常与失败处理 | **现金流断裂**：立即③；**叙事绑架**：强制④；**面子压力**：书面记录①；**坚持无信号**：转止损 |
| 关联模型卡 | M-D03-03；M-D03-04 |
| 来源类型 | T1 |
| 适用边界 | 决策止损，非证券交易细则 |

**演练（P6）**：WMS 定制越拖越久——①否+③是→止损转标准产品。
