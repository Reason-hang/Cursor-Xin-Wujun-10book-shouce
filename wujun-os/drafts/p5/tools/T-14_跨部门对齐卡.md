#### T-14 跨部门对齐卡　[T1]

| 字段 | 内容 |
|---|---|
| ID | T-14 |
| 名称 | 跨部门对齐卡 |
| 触发条件 | 多团队项目启动、职责不清、或互相甩锅 |
| 输入 | 项目目标；参与部门；可分享收益与不可妥协约束 |
| 步骤 | ① **利益**：写各方获益与付出（锚：P3a-GJ-U0007-K01）② **决策权**：关键决策谁独立拍板（锚：P3a-GJ-U0007-K01）③ **讨论纠错**：默认用讨论补盲区（锚：P3b-SG3-U0014-K01）④ **知识共享**：可分享模块扩大协作收益（锚：P3b-GG-U0027-K01）⑤ **边界**：助人能力与无私边界（锚：P3b-WJ2-U0090-K01；P3b-SG3-U0159-K01） |
| 输出 | RACI 简表 + 决策升级路径 + 下次同步时间 |
| 复查方式 | 里程碑是否仍符合②；扯皮是否减少 |
| 退出条件 | 项目结束或对齐表更新版本+1 |
| 异常与失败处理 | **集体绑架**：强制②单一负责人；**搬弄是非**：GJ-U0030 保持距离留痕；**线下关系缺失**：SG3-U0177 补慢关系 |
| 关联模型卡 | M-D07-03；M-D07-04 |
| 来源类型 | T1 |
| 适用边界 | 组织协作；商业合同条款归 D08 |

**演练（P6）**：OMS 与 WMS 联调——②指定集成 owner，⑤拒绝无限免费支援。
