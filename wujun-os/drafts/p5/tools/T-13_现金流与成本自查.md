#### T-13 现金流与成本自查　[T1]

| 字段 | 内容 |
|---|---|
| ID | T-13 |
| 名称 | 现金流与成本自查 |
| 触发条件 | 考虑新增投资/大额消费前，或月度财务失控 |
| 输入 | 近 3 个月收入与支出分类；固定义务；应急金余额 |
| 步骤 | ① **记账**：先分类再结论（锚：P3b-WJ2-U0077-K01）② **自由现金流**：收入−必要支出−义务（锚：P3a-JS-U0044-K01）③ **投资品 vs 消费品**：本次支出属哪类（锚：P3b-WJ2-U0229-K01）④ **红线快检**：杠杆/不懂/FOMO（锚：P3a-TD-U0025-K01）⑤ **结余动作**：仅当②为正才进入配置讨论（锚：P3a-JS-U0039-K01） |
| 输出 | 月度结余额 + 禁止项清单 + 是否进入投资配置 |
| 复查方式 | 每月同一天复盘；大额支出前重跑 |
| 退出条件 | 连续 3 月自由现金流为正或已触发削减计划 |
| 异常与失败处理 | **现金流为负**：停⑤，砍可变支出；**无记账**：只做①一周；**诱惑热点**：强制④ |
| 关联模型卡 | M-D09-02；M-D09-04 |
| 来源类型 | T1 |
| 适用边界 | 个人 household；非企业财报 |

**演练（P6）**：想换车——③消费品→②不足→延后并设 6 月储蓄目标。
