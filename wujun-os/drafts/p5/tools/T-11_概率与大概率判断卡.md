#### T-11 概率与大概率判断卡　[T1]

| 字段 | 内容 |
|---|---|
| ID | T-11 |
| 名称 | 概率与大概率判断卡 |
| 触发条件 | 重大决策前，或仅凭个案/爆款故事下结论 |
| 输入 | 命题；可得样本/基率来源；新证据 |
| 步骤 | ① **基率**：同类事件大致概率从哪来（锚：P3b-GG-U0324-K01）② **更新**：有新证据则贝叶斯一步（锚：P3a-SX-U0043-K01）③ **大概率**：是否值得押注（锚：P3a-GJ-U0015-K01 主 D03，决策语境）④ **叙事绑架**：是否只有赢家故事（锚：P3b-GG-U0324-K01）⑤ **行动**：小步验证或放弃（锚：M-D03-04） |
| 输出 | 采用/暂缓/拒绝 + 一条验证实验 |
| 复查方式 | 实验到期日复核 |
| 退出条件 | 验证完成或明确不赌 |
| 异常与失败处理 | **无基率**：标「不确定」不重仓；**情绪恐慌/贪婪**：强制④ |
| 关联模型卡 | M-D03-04；M-D04-03 |
| 来源类型 | T1 |
| 适用边界 | 决策层；非 D04 数学证明 |

**演练（P6）**：供应商单一来源风险——①行业断供基率未知→③小批量双源试点。
