#### T-10 职业选择与迁移盘点　[T1]

| 字段 | 内容 |
|---|---|
| ID | T-10 |
| 名称 | 职业选择与迁移盘点 |
| 触发条件 | 考虑跳槽、转行、或应对裁员/行业下行信号 |
| 输入 | 技能栈清单；近 12 月行业/岗位需求观察；可动用现金流月数；外部能见度（作品、社区、内推网） |
| 步骤 | ① **可迁移性**：标出 3 项可跨公司/行业复用的能力（锚：P3b-WJ2-U0041-K01）② **折旧判断**：技术栈/岗位需求是否走下坡路（锚：P3b-WJ2-U0060-K01）③ **窗口决策**：夕阳则列迁移能力与验证项目，非夕阳则升级不可替代性（锚：P3b-WJ2-U0247-K01；P3b-GG-U0286-K01） |
| 输出 | 一页决策：扛 / 转 / 升级 + 90 天行动 + 现金流红线 |
| 复查方式 | 90 天复盘：验证项目是否获得外部正反馈 |
| 退出条件 | 新赛道拿到 offer/项目签收，或确认留任且风险可控 |
| 异常与失败处理 | **数据不足**：只做①②不写③；**目标冲突**：家庭现金流与冒险转型冲突→延长窗口；**条件改变**：签证/地域限制→改步骤③范围（锚：P3b-WJ2-U0235-K01）；**失败**：验证项目无反馈→收窄赛道或回 M-D06-02 深耕 |
| 关联模型卡 | M-D06-03 |
| 来源类型 | T1 |
| 适用边界 | 职业机制判断；不构成投资或移民建议 |

**演练（P6）**：供应链 PM 从传统 ERP 转跨境履约平台——步骤①突出系统集成与数据能力；异常——行业仍增长但岗位技能老化 → 步骤②③走升级而非转行。
