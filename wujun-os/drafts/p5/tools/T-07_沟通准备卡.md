#### T-07 沟通准备卡　[T1]

| 字段 | 内容 |
|---|---|
| ID | T-07 |
| 名称 | 沟通准备卡 |
| 触发条件 | 重要会议、说服汇报、或易误解的敏感沟通前 |
| 输入 | 沟通对象；欲达成的单一目的；已知分歧点 |
| 步骤 | ① **目的**：先写一句话目的（锚：P3a-JS-U0074-K01）② **倾听**：列出对方诉求并预演复述（锚：P3b-GG-U0231-K01）③ **讲理**：选对方听得进的逻辑或故事（锚：P3a-JS-U0075-K01）④ **说服三要素**：信誉、逻辑、利益一致自检（锚：P3a-JS-U0076-K01）⑤ **结构**：演讲/汇报三段式服务听众（锚：P3a-JS-U0077-K01） |
| 输出 | 一页提纲 + 期望的对方确认句 |
| 复查方式 | 会后对方能否复述你的核心结论 |
| 退出条件 | 已确认共识或明确记录未决点 |
| 异常与失败处理 | **情绪升级**：降速换高带宽（见 D06）；**过度解读弦外之音**：用 WJ2-U0217 反复确认；**无过错勿乱道歉**：见 SG3-U0105 |
| 关联模型卡 | M-D07-01；M-D07-02 |
| 来源类型 | T1 |
| 适用边界 | 沟通准备；职场价值展示归 D06 |

**演练（P6）**：供应链方案评审——③用业务 KPI 故事而非技术细节堆叠。
