#### T-09 稀缺性与定价检查　[T1]

| 字段 | 内容 |
|---|---|
| ID | T-09 |
| 名称 | 稀缺性与定价检查 |
| 触发条件 | 考虑免费、补贴或降价抢市场 |
| 输入 | 目标用户；可交付的「优质/独特」要素；单位成本；竞品免费边界 |
| 步骤 | ① **稀缺**：核心用户/内容是否真稀缺（锚：P3a-GJ-U0059-K01）② **免费代价**：复制无价值免费会否死亡（锚：P3a-GJ-U0060-K01）③ **变现单元**：ARPU 路径是否清晰（锚：P3a-GJ-U0059-K01）④ **商业模式**：谁付钱、为何多花钱（锚：P3a-JS-U0007-K01）⑤ **超越免费**：有无时效/个性/可靠等可付费维度（邻界 D10，锚：P3a-GJ-U0061-K01 主归属 D10） |
| 输出 | 免费范围 + 付费锚点 + 不做的补贴项 |
| 复查方式 | 30 天单位经济复盘 |
| 退出条件 | 付费试点达标或明确关停免费实验 |
| 异常与失败处理 | **只有流量**：强制③；**恶性补贴**：②+关停；**定价无依据**：④ |
| 关联模型卡 | M-D08-04；M-D08-01 |
| 来源类型 | T1 |
| 适用边界 | 商业定价，非证券估值 |

**演练（P6）**：供应链数据产品免费看板——①核心仓主 scarce→③按仓计费试点。
