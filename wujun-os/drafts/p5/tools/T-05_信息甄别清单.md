#### T-05 信息甄别清单　[T1]

| 字段 | 内容 |
|---|---|
| ID | T-05 |
| 名称 | 信息甄别清单 |
| 触发条件 | 重要决策前读到「专家观点」、行业报告或社交媒体爆款结论 |
| 输入 | 信息原文或摘要；信息源身份；你的决策赌注大小 |
| 步骤 | ① **来源**：是否一手观察或可追溯到一手（锚：P3a-JJ-U0024-K01）② **细节**：能否回答 3 个具体「如何发生」（锚：P3b-WJ2-U0301-K01）③ **可复现**：是否有独立同行可验证（锚：P3b-WJ2-U0301-K01）④ **证伪**：主动找 1 条反例或替代解释（锚：P3a-JJ-U0019-K01）⑤ **搜索边界**：搜索只作线索，结论须自证（锚：P3b-SG3-U0093-K01） |
| 输出 | 三级结论：采用 / 暂缓 / 拒绝，并写一句理由 |
| 复查方式 | 决策结果出来后回看：哪条信息误导了你 |
| 退出条件 | 赌注高的决策已完成甄别记录；低赌注可简化到步骤①② |
| 异常与失败处理 | **数据不足**：标暂缓，缩小决策规模；**目标冲突**：多方信源矛盾→升维问共同前提；**条件改变**：利益相关方变化→重跑①；**失败**：采纳后翻车→更新个人信源黑名单 |
| 关联模型卡 | M-D01-07；M-D01-06 |
| 来源类型 | T1 |
| 适用边界 | 认知辨伪，非法律合规尽职调查替代 |

**演练（P6）**：正常——有厂商白皮书；异常——只有 KPI 截图无案例 → 拒绝或暂缓。
