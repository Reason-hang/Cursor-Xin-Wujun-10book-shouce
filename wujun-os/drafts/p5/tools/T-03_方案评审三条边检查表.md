#### T-03 方案评审三条边检查表　[T1]

| 字段 | 内容 |
|---|---|
| ID | T-03 |
| 名称 | 方案评审三条边检查表 |
| 触发条件 | B 端方案/技术设计评审、重大项目立项前 |
| 输入 | 方案摘要；团队现有能力清单；理论/行业最佳上限（可粗估） |
| 步骤 | ① **下边·基线**：是否站在已有工程/业务知识之上，而非从基线下蛮干（锚：P1-GG-U0013-K01）② **上边·极限**：目标是否触及可论证的上限或违背基本规律（锚：P1-GG-U0013-K02）③ **第三条边·路径**：是否有从基线到目标的可执行攀登路径与里程碑（锚：P1-GG-U0013-K02）④ **硬技能**：关键硬技能是否具备（锚：P3b-GG-U0084-K01）⑤ **行动教训**：是否来自可验证行动而非只听不做（锚：P3b-SG3-U0087-K01） |
| 输出 | 评审结论：通过 / 补基线 / 改路径 / 否决；附缺失边说明 |
| 复查方式 | 里程碑复盘时对照③是否仍成立 |
| 退出条件 | 三条边均有书面记录且责任人明确 |
| 异常与失败处理 | **基线不足**：降级范围或先补课；**路径缺失**：禁止开工只写 PPT；**极限不成立**：回 D03 取舍；**评审流于形式**：强制⑤举反例 |
| 关联模型卡 | M-D05-01；M-D05-02 |
| 来源类型 | T1 |
| 适用边界 | 做事方法评审；极限数学证明归 D04 |

**演练（P6）**：跨境履约中台方案——基线为现有 OMS 能力，路径分三期，缺数据基线则否决全量替换。
