#### T-12 创新与产品想法验证卡　[T1]

| 字段 | 内容 |
|---|---|
| ID | T-12 |
| 名称 | 创新与产品想法验证卡 |
| 触发条件 | 新功能/新产品/创业想法待投入资源 |
| 输入 | 问题陈述；目标用户；竞品或替代；可动用现金流月数 |
| 步骤 | ① **问题驱动**：是否真痛点（锚：P3b-GG-U0304-K01）② **N+1 或颠覆**：改进路径是否可验证（锚：P3a-JS-U0015-K01）③ **关键指标**：1–3 个够好且可交付阈值（锚：P3a-JS-U0018-K01）④ **起势要素**：定位/网络效应/节奏（锚：P3b-GG-U0335-K01）⑤ **现金流与避坑**：销售与现金流、伪需求（锚：P3a-JS-U0016-K01；P3b-WJ2-U0063-K01） |
| 输出 | 做/不做 + 90 天验证计划 + 停止条件 |
| 复查方式 | 90 天对照指标；未达标即停 |
| 退出条件 | 验证通过进入迭代或明确关停 |
| 异常与失败处理 | **无用户访谈**：停①；**只有功能无指标**：强制③；**现金流<3月**：强制⑤降级 |
| 关联模型卡 | M-D10-01；M-D10-02；M-D10-04 |
| 来源类型 | T1 |
| 适用边界 | 产品/创业想法；非证券 |

**演练（P6）**：供应链 AI 助手——①仓主痛点有→③出库准时率→⑤现金流 4 月→做 90 天试点。
