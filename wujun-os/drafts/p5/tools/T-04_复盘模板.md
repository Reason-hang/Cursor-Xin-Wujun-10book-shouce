#### T-04 复盘模板　[T1]

| 字段 | 内容 |
|---|---|
| ID | T-04 |
| 名称 | 复盘模板 |
| 触发条件 | 项目阶段结束、上线后、或重大故障后 |
| 输入 | 时间线；关键决策记录；中间交付物与数据 |
| 步骤 | ① **分步记录**：按节点列出中间结果（锚：P3a-FZ-U0027-K01）② **决策日志**：重大分支为何如此选（锚：P3b-WJ2-U0181-K01）③ **可复用**：哪些产物可进下一项目（锚：P3a-FZ-U0022-K01）④ **市场校验**：是否误把身边偏好当大众（锚：P3a-FZ-U0040-K01）⑤ **节奏**：是否走走停停拉低平均速度（锚：P3a-FZ-U0019-K01） |
| 输出 | 复盘一页纸：事实线 / 根因 / 改进行动 ≤3 条 |
| 复查方式 | 下次同类项目对照改进行动是否执行 |
| 退出条件 | 改进行动已纳入流程或 backlog |
| 异常与失败处理 | **无中间记录**：从①起补建日志习惯；**只表扬不挖根因**：强制②；**复盘无人负责**：指定 owner |
| 关联模型卡 | M-D05-03；M-D05-04 |
| 来源类型 | T1 |
| 适用边界 | 执行复盘；个人成长叙事归 D02 |

**演练（P6）**：大促库存偏差——②发现未记录分仓策略变更→③沉淀决策模板。
