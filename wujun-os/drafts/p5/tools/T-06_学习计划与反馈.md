#### T-06 学习计划与反馈闭环　[T1]

| 字段 | 内容 |
|---|---|
| ID | T-06 |
| 名称 | 学习计划与反馈闭环 |
| 触发条件 | 新技能/新领域学习启动，或季度能力复盘 |
| 输入 | 学习目标（可观察）；当前水平自评；可用周学时 |
| 步骤 | ① **手脑序**：先定「先做小实验还是先读书」（锚：P3a-FZ-U0032-K01）② **主动实验**：设计对比/跨界小项目，不只被动经历（锚：P3a-FZ-U0030-K01）③ **体系线**：选 1 条主线阅读+结论句笔记（锚：P3b-SG3-U0153-K01）④ **引路人**：找 1 次可追问反馈（锚：P3a-GJ-U0033-K01）⑤ **反馈**：能独立演示或教会他人一项（锚：P3a-FZ-U0025-K01） |
| 输出 | 4 周学习计划表 + 1 页经验结论句 |
| 复查方式 | 第 4 周：能否无提示完成演示；否则缩目标重跑② |
| 退出条件 | 目标技能达「可迁移」标准或宣告暂停并记录原因 |
| 异常与失败处理 | **时间不足**：只保留②最小实验；**方向错误**：用 M-D02-08 找全因再叠加；**只有输入无输出**：强制⑤；**导师不可得**：用公开作品对标替代 |
| 关联模型卡 | M-D02-02；M-D02-06；M-D02-08 |
| 来源类型 | T1 |
| 适用边界 | 个人学习，非企业培训体系设计 |

**演练（P6）**：学跨境关税规则——②单票模拟；异常——周学时<2h → 缩为 1 个实验+1 本书单章。
