#### T-01 取舍卡　[T1]

| 字段 | 内容 |
|---|---|
| ID | T-01 |
| 名称 | 取舍卡 |
| 触发条件 | 多选项竞争同一时间/预算，或「既要又要」僵局 |
| 输入 | 候选事项列表；资源上限（人/钱/周）；主目标一句 |
| 步骤 | ① **主矛盾**：哪 1 项是西瓜（锚：P3a-JS-U0055-K01）② **减法**：删低价值项（锚：P3b-GG-U0104-K01）③ **约束**：写不可同时满足的条件（锚：P3b-GG-U0357-K01）④ **机会成本**：长期选项付什么短期代价（锚：P3b-WJ2-U0127-K01）⑤ **反对席**：是否只听赞同（锚：P3a-GJ-U0006-K01） |
| 输出 | 决策：做 A / 做 B / 都不做 / 延期；附 1 句机会成本 |
| 复查方式 | 4 周后看主目标指标是否被次要事项挤占 |
| 退出条件 | 已执行 Top1 或明确放弃并记录理由 |
| 异常与失败处理 | **信息不足**：延期并缩小实验；**利益冲突**：升维到可交换约束；**情绪绑架**：强制⑤；**全都要**：强制③砍并行 |
| 关联模型卡 | M-D03-01；M-D03-02 |
| 来源类型 | T1 |
| 适用边界 | 个人与团队优先级，非法律合规裁决 |

**演练（P6）**：两条供应链项目争同一研发——③④后只留履约核心链路。
