#### T-08 伪工作与有效忙碌自检　[T1]

| 字段 | 内容 |
|---|---|
| ID | T-08 |
| 名称 | 伪工作与有效忙碌自检 |
| 触发条件 | 周/月复盘时感到「很忙但没进展」，或晋升答辩前需区分真贡献与流程空转 |
| 输入 | 近 4 周任务清单；每项的可验证产出（指标、上线、对方签收） |
| 步骤 | ① **对照目标**：本周最重要 1–3 项是否与岗位/项目主目标一致（锚：P3a-JS-U0026-K01）② **可衡量检验**：划掉无法被第三方验证的「伪产出」（锚：P3a-JS-U0027-K01）③ **可见性同步**：对保留项选 1 次高带宽同步，让关键人看见（锚：P3a-GJ-U0024-K01） |
| 输出 | 「真工作」清单 ≤5 条 + 已同步对象名单 |
| 复查方式 | 2 周后看真工作项是否带来机会/资源变化；无变化则查 M-D06-01 环境匹配 |
| 退出条件 | 真工作占比稳定 ≥60% 或确认需换岗/换赛道 |
| 异常与失败处理 | **数据不足**：先只做步骤②删伪项；**目标冲突**：用 M-D06-03 做赛道判断；**条件改变**：组织换领导/方向则重跑①；**失败**：忙但全删光→检查目标是否被错误设定（M-D06-02） |
| 关联模型卡 | M-D06-01；M-D06-02 |
| 来源类型 | T1 |
| 适用边界 | 职场效能语境；非替代 D05 项目管理方法论 |

**演练（P6）**：正常——有周报数据；异常——业务方临时全插单导致清单爆炸 → 先保 1 项主目标再同步。
