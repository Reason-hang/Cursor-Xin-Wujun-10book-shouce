# wujun-os 恢复包

**这是什么**：吴军十书整合工程的状态外置包（规格、状态、台账、脚本、交接文档）。运行环境闲置会被回收，上下文也会多次压缩，所以状态必须在这里，不在对话里。

**30 秒恢复**（在解压后的 wujun-os/ 下，路径按你的实际位置）：

```bash
cp "<10本书zip的完整路径>" ./_打包吴军10本电子书.zip
make restore-check
```

**每次收工**：`make pack`，然后下载 dist/ 里最新的 zip。

| 目录 | 内容 |
|---|---|
| handover/ | 项目交接文档、开场提示词（新窗口先读） |
| spec/ | v2 方案、工程化总纲、稳定性方案、硬约束、复水测验、基线 |
| state/ | 状态、日志、工单板、决策、变更、会话简报 |
| ledger/ | 进度台账 |
| scripts/ | 冻结、探测、锚点、状态、打包、自测 |
| src_frozen/ | 原文（由你保管，脚本冻结并核对哈希） |

**交付纪律**：批次顺序、阶段快照、最小可交付——一次一个批次，每批先交 MVD，结束就 `make pack`。额度中断已发生 1 次（2026-10-20）。
