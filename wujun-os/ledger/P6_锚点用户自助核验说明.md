> 与 `make verify-anchors` 同源；你可独立复跑，不依赖 Agent 口头结论。

## 1. 全量校验（509 条合并锚点）

```bash
cd "/Users/lizhihang/Documents/【Cursor-projects】/Cursor-Xin-Wujun-10book-shouce/wujun-os"
make verify-anchors
```

- **PASS**：台账中每行 SHA1、行号、字符区间与 `src_frozen/` 对应文件一致。
- **FAIL**：记下卡 ID，对照 `ledger/P6_锚点修探针建议.md`；修锚须你批准队列后再 `anchor_tool make`。

## 2. 单条抽查

从 `ledger/溯源与处置台账.md` 或 D3 副本取卡 ID、书文件名、行起止，在 `src_frozen/` 打开对应段落，对照 `cards/` 内该卡 `claim`。

## 3. 与 claim 质控区分

- **SHA PASS** 只证明「段落未篡改」，不证明「段落承载 claim」。
- claim↔锚点语义问题见 `ledger/P4_抽查20张_锚点快核_SA5.md` 与 `P6_锚点修探针队列.csv`。

## 4. 打包后复验

```bash
make pack && make verify-pack
```

恢复包不含 `src_frozen/`；核验前须本地已有冻结原文（`make freeze` 或你的备份 zip）。
